# AI 面试陪练 / AI Interview Coach

面向 AI 产品经理实习候选人的文本面试陪练。依据简历与 JD 生成针对性问题，以回答证据驱动追问、评分和改进建议，而不是随机聊天。

## 当前功能

- 简历文本与 JD 匹配分析。
- 生成 5 道问题：2 道简历核验、2 道岗位能力、1 道场景迁移。
- 根据回答决定是否进行追问，当前界面每题最多 1 次。
- 提供 6 维评分、改进建议和可展开参考回答。
- 最终可切换快速总结和深度报告。
- DeepSeek JSON 输出 + 本地 Schema 校验；密钥只在服务端使用。

PDF 目前仅支持选择文件，尚未实现解析，仍需粘贴文本。上传代码不等于所有功能已经完成线上验证：分析与出题经过真实 API 测试，评分和深度报告还需端到端评测。仓库内 PRD/工作流文档包含后续设计目标，不代表功能全部实现。

## 本地运行

需要 Node.js 20 或以上。不需要安装第三方依赖。

在项目根目录创建 `.env.local`：

```env
DEEPSEEK_API_KEY=填写你自己新创建的Key
DEEPSEEK_MODEL=deepseek-flash
PORT=4180
```

```sh
node server.js
```

浏览器打开 `http://127.0.0.1:4180/ai-interview.html`。请不要双击 HTML。先载入虚构测试样本；模型生成会消耗账户余额。

## 测试

```sh
node --test tests/deepseek-client.test.mjs tests/server-smoke.test.mjs
```

测试使用模拟接口和虚构 Key，不产生模型费用。覆盖 DeepSeek 请求格式、缺失 Key、余额不足、格式错误、截断输出与私有文件访问保护。

## GitHub 与在线部署

GitHub 保存源码。GitHub Pages 只支持静态页面，不能运行此 Node 后端或安全保存 API Key，因此 Pages 页面不是可以真实调用模型的在线产品。

当前服务仅监听本机，并限制同源请求。若要让其他用户在线使用，需要另行选定 Node 托管服务，配置服务端 Key，并补充公网监听、访问控制、限流、费用保护和部署测试。**不要直接把本地 Key 写入前端，也不要为了让 Pages 能调用模型而公开 Key。**

## 隐私与风险

- `.env.local` 不得提交 Git。不要上传实际简历、练习记录、代理备份或账户资料。
- 页面内测试候选人是虚构资料；生产使用时简历/JD/回答会发送给 DeepSeek。
- 本地服务不持久化保存输入；这不等同于模型供应商不会保留处理记录。
- 参考回答仅用于训练，不应补造经历；评分不代表招聘结论。
